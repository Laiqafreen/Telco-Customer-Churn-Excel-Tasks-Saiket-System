# Excel Customer Churn Analysis

This repository contains my Excel-based Customer Churn Analysis project. The tasks focus on data organization, visualization, and basic customer churn analysis using Microsoft Excel.

## Tasks Completed

### Task 1 — Data Overview & Sorting
**File:** `Task_1_Data_Overview_Sorting.xlsx`

- Reviewed the customer churn dataset
- Organized and sorted the data
- Performed basic data cleaning
- Removed blank rows where required
- Created an overview of the dataset

### Task 2 — Churn Count Visualization
**File:** `Task_2_Churn_Count_Visualization.xlsx`

- Analyzed customer churn counts
- Compared customers who churned and did not churn
- Created a chart to visualize the churn distribution

### Task 3 — Monthly Charges Histogram
**File:** `Task_3_Monthly_Charges_Histogram.xlsx`

- Analyzed the distribution of monthly customer charges
- Created a histogram using Monthly Charges
- Added appropriate chart title and axis titles
- Used the histogram to understand the distribution of customers across charge ranges

### Task 4 — Customer Churn by Gender
**File:** `Task_4_Customer_Churn_By_Gender.xlsx`

- Created a PivotTable to analyze customer churn by gender
- Compared churn status between Female and Male customers
- Created a PivotChart using the PivotTable
- Visualized the number of customers who churned and did not churn by gender

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Charts
- Data Sorting and Cleaning
- Histogram

## Dataset

The project uses a Telco Customer Churn dataset containing customer information, services, billing details, and churn status.
